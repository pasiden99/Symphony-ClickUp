# Changelog

All notable changes to Symphony ClickUp are documented here.

This project follows versioned releases, but this changelog was added after the early release history. Entries before `0.8.1` are summarized from repository commit history.

## Unreleased

### Added

- Added open-source project documentation for contributors and security reporting.
- Added user-guide pages for compatibility, configuration, operations, and troubleshooting.

### Changed

- Trimmed the root README into a shorter entry point with links to detailed user-guide pages.
- Fixed the codebase map so local-only agent instruction files are not listed as authored project files.

## 0.8.1 - 2026-05-02

### Changed

- Improved license and workflow merge-conflict handling documentation.

## 0.8.0 - 2026-04-26

### Added

- Added opt-in Playwright screenshot capture for local visual review.
- Added a first-party screenshot dynamic tool that can attach screenshots to ClickUp tasks.
